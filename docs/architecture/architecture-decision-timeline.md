# School OS Architecture Decision Timeline (2026 ➔ 2030)

> Peta sejarah dan rencana keputusan arsitektur platform School OS untuk kemudahan onboarding pengembang baru.

---

## Strategic Timeline

```text
2026: Core Operations Foundation
   ├── Identity, Multi-Tenant RLS, & Academic Core
   ├── Learning Operations Workspace (Materials, Lessons, Assignments, Quizzes)
   ├── Assessment Engine & Spreadsheet GradeBook
   └── Reporting Domain & Parent Awareness Portal (/parent)

2027: Automation & Platform Extensions
   ├── Finance Domain (SPP & Billing)
   ├── Library Management & PPDB Admissions Modules
   └── Background Job Queue, Document Storage Domain, & Search Context

2028: Enterprise Integration Layer
   ├── Public Integration Adapters (Dapodik, Google Classroom, Teams, Zoom)
   ├── Public REST API v1 & Auto-Generated SDKs
   └── OAuth2 Provider & Webhooks Subsystem

2029: School Intelligence Platform (Level 8)
   ├── AI Recommendation Engine & Copilot
   └── Human-in-the-Loop Governance Automation
```
